---

PromptFuzz 전체 검증을 다음 순서로 실행해라:

1. `npm run typecheck` 실행. 종료 코드 확인.
2. `npm run build` 실행. `dist/cli.js` 생성 여부 확인.
3. `npm test` 실행. 통과한 테스트 개수와 실패 개수 추출.

마지막에 다음 형식 한 줄 요약 출력:

```
typecheck: ✅ / ❌
build:     ✅ / ❌
test:      ✅ / ❌  (N/M 통과)
종합:      ✅ 모두 통과 / ❌ 실패 있음
```

하나라도 실패하면:
- 실패한 명령의 에러 출력을 그대로 표시
- **수정 시도 금지.** 사용자에게 "다음 단계 지시 대기 중"이라고 말하고 멈춰라.

모두 성공이면 한 줄 요약만 출력하고 끝.
